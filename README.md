### SMS 인증 설정

문자 인증을 사용하려면 **서버 프로세스 환경변수** `COOLSMS_API_KEY`와 `COOLSMS_API_SECRET`을 설정하고 서버를 다시 시작해야 합니다. 값이 누락되면 문자 발송은 즉시 중단됩니다. 환경변수 값이나 실제 발급 키는 Git에 추가하지 마세요. 과거 Git 기록에 포함된 CoolSMS 키는 공급자 콘솔에서 폐기하고 새로 발급해야 합니다.

Google Maps JavaScript API 키는 브라우저에서 공개되는 유형입니다. 운영 중인 키에는 Google Cloud Console에서 **HTTP 리퍼러(실제 서비스 도메인)** 및 **Maps JavaScript API만 허용**하는 API 제한을 적용하고, 기존 공개 키는 교체해야 합니다.
